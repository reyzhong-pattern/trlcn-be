# data/ — local real data only (git-ignored)

Real room-export files and any other real data go here **on your machine only**. `.xlsx`, `.xls`, `.csv`, `.parquet` and `.json` files anywhere under `data/` are ignored by git ([../.gitignore](../.gitignore)). Never force-add them (AGENTS.md rule 5). This README is the only tracked file here.
